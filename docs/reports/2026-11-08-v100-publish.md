# v1.0.0 の公開検証

2026-11-08 に Simple Pitch Shift v1.0.0 を GitHub Release で公開し、配布物の再取得照合を完了した。OBS Forum の概要とダウンロード先も更新した。Forum の更新履歴 8825 は審査待ちであり、一般公開の完了として扱わない。

## 公開対象

[PR #3](https://github.com/AllegroMoltoV/obs-simple-pitchshift/pull/3) を `main` へ統合した。統合コミットとタグ `v1.0.0` の対象は `deaa935ca02d2d713b0f816b431f0c0ba52fda8c` である。

公開範囲は Signalsmith Stretch による声質保持、40 ms の DSP、OBS Studio 33 以降向け Windows 配置、ロゴ、ライセンス同梱と依存ソース配布である。依頼者 AllegroMoltoV の使用感確認と公開承認に基づいて実施した。旧 v0.1.0 の公開資産を保持した。

英語 locale で空白を含む表示名が引用符なしで記述され、`Simple` と解釈される従来の不具合も修正した。新版の表示名は `Simple Pitch Shift` とし、旧版からの更新試験だけで旧表示名を許容した。

## OBS Forum の状態

リソース 2338 の概要、ソース URL、ダウンロード URL、ロゴを更新して保存した。既存の PNG スクリーンショットを保持し、AI 利用開示を日英で更新した。概要本文の実測版を OBS Studio 33.0.1 とし、選択式の対応版欄を 33.0.0 とした。

## 保護設定と通常環境

承認済みの統合操作に必要な間だけ ruleset `11737366` を無効にした。無効期間は約 4 秒であり、統合直後に `active` へ戻し、変更可能な全設定の一致を確認した。

通常環境では OBS が起動していない状態で試用 DLL を退避し、ProgramData に最終 v1.0.0 を導入した。設定を変更せず、配置した DLL の SHA256 と英語 locale を確認した。この導入後の通常 OBS は未起動であり、通常環境での最終版の再試用結果は含めない。
