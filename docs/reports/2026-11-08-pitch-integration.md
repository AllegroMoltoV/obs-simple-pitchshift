# v1.0.0 のピッチシフト統合検証

2026-11-08 に、Signalsmith Stretch を使用する 40 ms 設定の統合候補を検証した。Windows の通常環境で作者が使用感を確認し、採用した。同日、DSP と Windows 配置変更を含む v1.0.0 を GitHub Release で公開した。最終配布物の検証と Forum の審査状況を [公開検証報告](2026-11-08-v100-publish.md) に記録した。

## 採用構成

| 項目 | 内容 |
|---|---|
| Signalsmith Stretch | `88061fd4eda56a2353c5d65c74aa3f4ccf76f9da` |
| Signalsmith Linear | `7bb1c8f36794d6980080ce817c91f8da8fe56a66` |
| 処理窓 / 更新間隔 | 40 ms / 10 ms、計算分散なし |
| 声質補正 | 有効、基音概算 180 Hz 固定 |
| 対応音声 | 44.1 kHz / 48 kHz、ステレオ |
| 設定 | 整数 ±12 半音、既定値 0 |
| 互換性 | `simple_pitchshift_filter` と `semitone` を維持 |

左右の音声を同一の処理インスタンスへ渡す。対応する 2 つのサンプルレートの処理状態を生成時に準備する。0 半音と対応外音声ではバイパスし、設定変更と再有効化時に履歴を初期化する。音声タイムスタンプから DSP の遅延を差し引く。

## 検証結果

Windows 11、OBS Studio 33.0.1 で次の結果を得た。

| 対象 | 結果 |
|---|---|
| 44.1 kHz / 48 kHz の -12、-3、0、+3、+12 半音 | 全条件で成功。有限値、全フレーム処理、設定復元、タイムスタンプの整合を確認 |
| 0 半音 | 入力を加工せず通過し、タイムスタンプの遅延補正は 0 |
| 無効化と再有効化 | 無音区間に古い音声が再生されないことを確認 |
| +3 → -3 → 0 → +3 半音 | 両サンプルレートで成功。切替後の無音と代表音声を確認 |
| 48 kHz、±3 半音の最終ミックス | 有限値、連続したタイムスタンプ、参照 PCM との一致を確認。最大 PCM 誤差は 0 |
| 保存後の別プロセス復元 | 48 kHz、±3 半音で保存設定を復元し、最終ミックス検証に成功 |
| 通常 OBS での使用感 | 作者が問題なしと評価し、40 ms 設定を採用 |

単音測定はピッチ変換の診断として実施した。単音の周波数誤差だけを音質合格の根拠にせず、代表音声と作者の使用感確認を採用判断に用いた。

[CI run 42420765811](https://github.com/AllegroMoltoV/obs-simple-pitchshift/actions/runs/42420765811) で Windows、macOS、Linux の製品ビルドが成功した。macOS と Linux の実機動作は未確認であり、CI の成功を実機動作保証へ拡張しない。

## 遅延の測定範囲

非 0 半音の DSP 遅延と音声タイムスタンプの補正量は 40 ms で一致した。0 半音の補正量は 0 ms だった。

48 kHz の最終ミックス検証では、先頭の有音入力ブロックを渡した時点から、先頭の有音最終ミックスを受信するコールバックまでの実時間を記録した。

| 条件 | 診断値 |
|---|---:|
| +3 半音、保存前 | 45.454 ms |
| +3 半音、別プロセス復元後 | 53.168 ms |
| -3 半音、保存前 | 42.047 ms |
| -3 半音、別プロセス復元後 | 51.299 ms |

この診断値にはブロック単位の量子化と OBS のバッファリングを含む。音声デバイスへの出力を含まず、マイク入力から耳に届くまでの遅延ではない。約 42〜53 ms を製品の遅延保証値として扱わない。映像を含む測定を実施していないため、音声と映像の同期も本結果だけで保証しない。

## 配布と公開の確認範囲

Windows の対象を OBS Studio 33 以降とし、通常版では `%PROGRAMDATA%/obs-studio/plugins/simple-pitchshift`、ポータブル版では OBS ルートの `plugins/simple-pitchshift` を使用する。DLL を製品フォルダー直下に置き、`data` を同階層へ配置する。旧 v0.1.0 の公開資産を保持する。

通常版の配置検証 CI で新規導入と旧版からの更新に成功した。旧 DLL を保持して新しい配置の DLL が優先され、登録数 1、半音 +3、有効状態の保持を確認した。タグ CI の最終 ZIP でも OBS Studio 33.0.1 ポータブル版への新規導入に成功した。公開後に Windows ZIP とソースアーカイブを再取得し、検証済みファイルとの SHA256 一致を確認した。

依存ライセンスの確認結果を [別報告](2026-11-08-dependency-licenses.md) に記載した。MIT 本文 2 件と本体の GPL 本文を `data/licenses` へ同梱し、固定コミットの依存ソースを含むソースアーカイブを公開した。Forum の概要とダウンロード先を更新した。更新履歴 8825 の一般公開は審査待ちである。

## 証拠と限界

機械検証の JSON 結果から本報告の条件別結果と遅延を転記した。入力音声と個人環境のパスを含む生データは公開文書へ含めていない。公開している実装と CI を参照できるが、第三者が同じ個人音声で評価を再現するための素材は配布していない。

本検証は代表条件の統合動作と使用感を対象とする。すべての声質、歌唱、音声デバイス、OBS 設定に対する音質・遅延の保証ではない。コード読解による厳密な人間レビューは実施していない。
